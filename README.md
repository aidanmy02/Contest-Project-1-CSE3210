## Catchess

Welcome to Catchess! It's chess, but with... cats. To run the game, just run the exe in the Release folder and get to chessing.
If you want to start a new game, close out of the current one and start the exe again. Enjoy!
Note: All elements that were not learned in class are in Chess.inc marked with a comment starting with "Source:" and followed by a URL for the source.
